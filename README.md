Веб-приложение для эффективного запоминания иностранных слов и словосочетаний с использованием метода интервальных повторений (Spaced Repetition System).

## 🎯 Описание

**Training Words** — это полнофункциональное Django-приложение для изучения английских слов и фраз. Система автоматически планирует повторения на основе вашего прогресса, помогая эффективно переводить слова из кратковременной памяти в долговременную.

### Основные возможности

#### 📚 Управление словарём
- **Создание слов**: Добавление новых слов с автоматическим определением языка (русский/английский)
- **Автоперевод**: Автоматический перевод английских слов на русский язык при создании
- **Расширенная информация**: Возможность добавить определение, пример использования и изображение к слову
- **Уникальность**: Система предотвращает дублирование слов для каждого пользователя
- **Фразы**: Отдельный модуль для изучения словосочетаний и фраз

#### 🧠 Умная система повторений
- **Интервальные повторения**: Алгоритм на основе кривой забывания (1, 3, 7, 14, 30, 60, 90, 180, 365 дней)
- **Автоматическая активация**: Система автоматически добавляет новые слова в тренировку, когда количество активных слов уменьшается
- **Адаптивное обучение**: При неправильном ответе слово возвращается в активный пул через 1 час
- **Отслеживание прогресса**: Счётчик успешных повторений для каждого слова

#### 🎮 Режимы тренировки
- **Гибкие настройки**: Выбор между тренировкой слов, фраз или обоих типов
- **Карточная система**: Интерактивные карточки с возможностью показать/скрыть ответ
- **Статистика сессии**: Отслеживание правильных и неправильных ответов
- **Процент точности**: Автоматический расчёт успеваемости после завершения тренировки

#### 📊 Мониторинг и статистика
- **История тренировок**: Просмотр всех прошлых сессий с детальной статистикой
- **Категории слов**:
  - Активные слова (участвуют в тренировке)
  - Новые слова (в ожидании изучения)
  - Выученные слова (успешно пройденные)
- **Визуальная индикация**: Прогресс-бары и счётчики для каждой категории

#### 👤 Профиль пользователя
- **Персонализация**: Аватар, биография и личные данные
- **Управление словами**: Просмотр и редактирование всех добавленных слов и фраз
- **План изучения**: Расписание предстоящих повторений
- **Смена пароля**: Безопасное управление учётной записью

#### 📥 Экспорт данных
- **Выгрузка в CSV**: Экспорт активных слов с определениями для печати или использования в других приложениях
- **Проверка целостности**: Система предупреждает, если у слов отсутствуют определения перед экспортом

## 📦 Установка и запуск

### Требования
- Python 3.12+
- Docker и Docker Compose (для контейнеризованного запуска)
- uv (опционально, для управления зависимостями)

### Локальная разработка

1. **Клонирование репозитория**
```bash
git clone https://github.com/bobgoz/training_words_django.git
cd training_words_django
```

2. **Создание виртуального окружения и установка зависимостей**

С использованием uv (рекомендуется):
```bash
uv venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate  # Windows

uv pip install -e .
```

Или с использованием pip:
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

3. **Настройка переменных окружения**
```bash
cd src/training_words_django
cp .env.example .env
# Отредактируйте .env и установите необходимые значения
```

Минимальные настройки для локального запуска:
```env
SECRET_KEY=your-secret-key-here
DEBUG=true
ALLOWED_HOSTS=localhost,127.0.0.1
POSTGRES_USE=false
LOGGING_LEVEL=INFO
```

4. **Применение миграций**
```bash
python manage.py migrate
```

5. **Создание суперпользователя**
```bash
python manage.py createsuperuser
```

6. **Сбор статических файлов**
```bash
python manage.py collectstatic --noinput
```

7. **Запуск сервера**
```bash
python manage.py runserver
```

Приложение будет доступно по адресу: `http://localhost:8000`

### Запуск через Docker

1. **Клонирование репозитория**
```bash
git clone https://github.com/bobgoz/training_words_django.git
cd training_words_django
```

2. **Настройка окружения**
```bash
cd src/training_words_django
cp .env.example .env
# Отредактируйте .env
```

Для Docker Compose установите:
```env
SECRET_KEY=your-secret-key-here
DEBUG=true
ALLOWED_HOSTS=localhost
POSTGRES_USE=true
DB_NAME=your_name
DB_USER=username
DB_PASSWORD=password
DB_HOST=db
DB_PORT=5432
REDIS_URL=redis://redis:6379/0
```

3. **Запуск контейнеров**
```bash
cd ../..  # возврат в корень проекта
docker-compose up -d
```

4. **Применение миграций**
```bash
docker-compose exec web python manage.py migrate
docker-compose exec web python manage.py createsuperuser
docker-compose exec web python manage.py collectstatic --noinput
```

Приложение будет доступно по адресу: `http://localhost`

### Продакшн-деплой

Для продакшена используйте `docker-compose.prod.yml`:

```bash
docker-compose -f docker-compose.prod.yml up -d
```

⚠️ **Важно для продакшена:**
- Установите `DEBUG=false`
- Используйте сильный `SECRET_KEY`
- Настройте `ALLOWED_HOSTS` с вашим доменом
- Включите Dropbox Storage: `DROPBOX_USE=true` и настройте соответствующие ключи
- Настройте HTTPS и SSL сертификаты

## 📖 Использование

### Быстрый старт

1. **Регистрация**: Создайте учётную запись на странице регистрации
2. **Добавьте слова**: Перейдите в "Добавить слово" и начните создавать свой словарь
3. **Активируйте слова**: Отметьте слова как активные, чтобы они появились в тренировке
4. **Начните тренировку**: Перейдите в раздел "Тренировка" и выберите параметры
5. **Отвечайте честно**: Нажимайте "Знаю" или "Не знаю" — система автоматически подстроится

### Загрузка готовых слов

В проекте есть команда для загрузки готовых наборов слов:

```bash
python manage.py loaddata_csv
```

CSV-файлы находятся в `src/training_words_django/training/management/commands/`:
- `words.csv` — базовые английские слова
- `phrases.csv` — популярные фразы
